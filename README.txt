WANDERVERSE - BASIC COLLEGE HTML PROJECT

1. Open this folder in VS Code.
2. Put your own images into the images folder:
   hero.jpg, bali.jpg, japan.jpg, switzerland.jpg, iceland.jpg, santorini.jpg
3. Put your own media into the media folder:
   travel-audio.m4a and travel-video.mov
4. Open index.html in Chrome or with Live Server.
5. Click navigation links to explore all six pages.

This is a beginner-friendly demonstration project. The trip planner only
shows a summary in the browser. Feedback is not sent or saved.
The contact email is an example, not a real project inbox.
If video doesn't play, convert it to MP4 and update the source tag.

Concepts: HTML formatting, images, links, lists, tables, forms, inline/
internal/external CSS, selection, overlays, polka dots, scroll snapping,
bouncing animation, animated underline, aside, pre, audio, video, iframe.
